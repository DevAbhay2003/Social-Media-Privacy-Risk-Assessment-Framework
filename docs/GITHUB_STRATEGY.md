## 2. Step-by-Step Git Commands (Terminal Execution)

```bash
# 1. Initialize Git repository
git init

# 2. Stage all project files (respecting .gitignore)
git add .

# 3. Create initial foundational commit
git commit -m "Initialize social media privacy risk assessment"

# 4. Ensure primary branch is named 'main'
git branch -M main

# 5. Connect to your remote GitHub repository
# Replace <repository-url> with your GitHub repository link (e.g. https://github.com/yourusername/Social-Media-Privacy-Risk-Assessment.git)
git remote add origin <repository-url>

# 6. Push codebase to GitHub
git push -u origin main
```
